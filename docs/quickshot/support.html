QuickShot Support

Help with capture modes, annotations, export, and everything else in QuickShot.

Quickstart

  1. Install QuickShot from the Chrome Web Store.
  2. Click the QuickShot icon in the Chrome toolbar, or use the keyboard shortcut Alt + Shift + S (default).
  3. Pick a capture mode: Region, Visible, or Full Page.
  4. Annotate: pen, arrow, rectangle, circle, text, number, blur, pixelate, crop.
  5. Export: PNG, JPG, PDF, or copy to clipboard.

Capture Modes

Region Capture

Drag a rectangle anywhere on the page. Only that area is captured. Useful for capturing one element, one panel, or a custom size.

Visible Capture

Captures exactly what's visible in the current browser viewport, at the current zoom level. The fastest option for everyday use.

Full Page Capture

Captures the entire scrollable page, stitching multiple viewport scrolls into one image. Resolution is preserved for high-DPI / Retina screens.

Annotation Tools

  • Pen. Freehand drawing. Color and stroke width are adjustable from the toolbar.
  • Arrow. A directional marker with adjustable color and size.
  • Rectangle. A sharp, rectangular outline. Useful for bounding a region.
  • Circle. A round highlight or marker.
  • Text. A text label with adjustable font size and color.
  • Number markers. Drop numbered steps in sequence. Useful for tutorials and walk-throughs.
  • Blur. Smooths pixels behind a region. Good for light redaction of faces or names.
  • Pixelate. Mosaic-style redaction. Good for strong redaction of account numbers or email addresses.
  • Crop. Trim the canvas to a chosen rectangle.

Export Options

  • PNG. Lossless. The default for technical screenshots.
  • JPG. Smaller files with adjustable quality (configurable in settings).
  • PDF. A single-page PDF, ready to share.
  • Copy to clipboard. Pastes the image directly into chat or other apps.

The exported filename follows a customizable template. You can set the template in QuickShot's settings (for example, quickshot-{{date}}-{{time}}).

Frequently Asked Questions

Does QuickShot upload my screenshots anywhere?

No. QuickShot is fully local. It does not contact any server to process, store, or share your screenshots. See the Privacy Policy for details.

Do I need an account?

No account, no sign-in, no email. Install and use.

Does QuickShot track me?

No analytics, no advertising, no tracking SDKs, no third-party CDN scripts. The extension does not embed any network communication other than what the Chrome capture APIs require.

Will my screenshots show up in History automatically?

Only if you have not disabled the History feature in settings. History is stored locally in IndexedDB. You can clear it at any time from QuickShot's UI.

Can I disable the JPG quality setting?

Yes. QuickShot's settings panel exposes theme, default export format, JPG quality, filename template, and keyboard shortcut overrides. All settings are stored locally.

What about themes?

QuickShot follows your system theme. You can also force Light or Dark mode from the toolbar.

Reporting a bug

If QuickShot misbehaves, please email llcailabs@gmail.com with:

  • Chrome version (visit chrome://version)
  • Operating system
  • QuickShot version (visible in the extension's settings panel)
  • Steps to reproduce, with screenshots if possible (taken with QuickShot, of course).
