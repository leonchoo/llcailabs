About User-Agent Switcher

User-Agent Switcher is a lightweight Chrome extension that lets you instantly change the User-Agent your browser sends to websites. It is designed for web compatibility testing and development testing — for example, checking how a mobile site looks, or verifying that a page behaves correctly across browsers. All settings are stored locally on your device.

Features

  • One-click device presets. Switch between Android, iPhone, iPad, Windows, Mac, Edge and Firefox user agents from the toolbar popup.
  • Custom User-Agent. Paste any User-Agent string and save it for use globally or in per-site rules.
  • Per-site rules. Set a specific User-Agent for a chosen website while all other sites keep the global identity or Chrome’s default.
  • Global enable / disable. Pause simulation entirely with one switch.
  • Restore default. One click returns to Chrome’s native User-Agent.
  • Mobile hint. Mobile presets also send sec-ch-ua-mobile: ?1 for better mobile-site detection.
  • Manifest V3. Built with the current Chrome extension architecture; uses declarativeNetRequest to rewrite request headers and never injects scripts into pages.

Intended use

This extension is intended for web compatibility and development testing. It does not guarantee that you can bypass a website’s security checks, login restrictions, or anti-bot mechanisms. Changing the User-Agent does not alter every browser fingerprint (for example, real screen size, some Client Hints, or hardware information), so a few strict sites may still detect your real device.

Privacy

User-Agent Switcher does not collect personal data and does not send anything to any server. Your presets, custom User-Agents and per-site rules are saved only in Chrome’s local storage on your device.
