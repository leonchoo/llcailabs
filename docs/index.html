Privacy stance, in one line

If an app needs to know about you, we tell you. If it doesn't, we don't ask. The full per-app details are on the Privacy page and on each app's own page.

  • No account required.
  • All personal data is stored locally on your device.
  • Cloud backup (where offered) is opt-in and uses only the minimum required scope.
  • Ads, where present, are non-personalized by default and can be turned off in Settings.
